Fortalezas

  • RLS y aislamiento multiusuario estan mucho mejor que el promedio: el contrato reporta 39 tablas privadas y dominios smoke relevantes.
  • CI tiene gates con dientes: auth/RLS, runtime API routes, hard-delete, docs drift, ratchets, frontend boundaries y bundle.
  • TypeScript esta en buen estado: el typecheck completo paso en el checkout actual, incluyendo extension.
  • Hay cultura de PRs deployables: las mejoras recientes dejan tests, docs, scripts y runbooks en vez de solo cambios funcionales.
  • La disciplina de performance existe: budgets y lazy entrypoints PDF previenen que Imprenta degrade silenciosamente el bundle.

Debilidades

  • La deuda legacy operativa esta resuelta: produccion corre en Clerk estricto, anonimo responde 401 y el smoke A/B valida aislamiento de lectura, mutacion y blobs. Lo que queda es deuda historica opcional de reasignacion de datos.
  • Hay mega-archivos: whatsapp-webhook.mts ~1465 lineas, demoRouter.ts ~825, Icons.tsx ~896.
  • La capa de servicios de dominio aun es limitada: existen solo tres *-service.ts principales.
  • Demo mode duplica bastante comportamiento backend, aumentando el costo de cada feature nueva.
  • Los ratchets contienen la deuda, pero varios limites estan pegados al tamano actual de hotspots, no orientados a reduccion progresiva.
